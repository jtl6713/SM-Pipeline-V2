Set video length, spoken voiceover length, music in-point, voice, track, and the 3D grid cover.

      Support

      A full idea-to-publish walkthrough, then a guide for each Studio page.

      Idea through publish on every platform

      This is the photo-based path ChicagoShining Studio uses today: write or pick an idea, attach stills, let Studio plan the packages, review the renders, then approve. Instagram, Facebook, and YouTube publish publicly. TikTok is saved as a draft.

      1. Confirm the city in the top bar. The profile (Chicago, New York, Los Angeles) stamps branding, defaults, and which library the new work uses. Change it anytime from Profile in the header.
      2. Start in the publishing wizard. On Home, answer where you want to start: an idea, photos you already have, AI images, or a mix. Then pick a platform package. Ideas and Production stay in the sidebar if you already know the path.
      3. Add photos from the idea drawer. Open the idea, then Add new photos or Use existing. New uploads start an empty Production request. Library stills attach first, then you customize. Studio builds a multi-platform plan from the photo count, not from a content-type picker on the idea.
      4. Confirm platforms and crops in Production. Two default packages. Vertical video: Instagram Reel, Facebook Reel, TikTok draft, YouTube Short, plus Instagram and Facebook 9:16 Stories and a grid thumbnail. Voiceover and music stay on. Scrollable slides: Instagram carousel, Facebook album, TikTok photos; YouTube is a rendered Slideshow Video (no image post). First slide can introduce a multi-day event; later slides hold the details. Reframe crops, write or AI-fill captions, then Save.
      5. Approve & Promote. Production hands the request to render. Companion Stories attach from the same 9:16 stills. YouTube 16:9 covers can finish in the background; 9:16 plan crops are enough to continue.
      6. Watch Pipeline until Ready for Review. Open Platform Pipeline. Rows move through package, asset selection, Remotion render, and review mail. Click a row to open the creative editor: preview, audio mix, per-photo titles, then Save & rerender preview if you change the mix.
      7. Approve for publishing. When the preview is right, Approve for publishing (or Pipeline Approve All). Confirm the public/draft warning. Studio stages a public R2 URL (AP0) for video, then:
        • Instagram Reel — auto-publish to the professional account
        • Instagram Story companion — AP1 story webhook
        • Facebook Slideshow Reel — FBS3 / FBS4
        • Facebook Story companion — Graph binary upload
        • TikTok Video Draft — TTD0 (stays a draft in TikTok)
        • YouTube Short — YouTube orchestrator when the row is due
        Carousels, Facebook multi-image, and TikTok multi-photo use the native still packages instead of a Remotion reel. Those publish through their own carousel / photo paths after the same Approve.
      8. Confirm in Operations if you need a clock or a manual mark. Ready to schedule lists approved rows that still need a post time. Ready to publish lists due packages. Use mark published only when you posted by hand. Daily ideas, Drive intake, and render repair live on the same page (admin roles).

      Other entry: Home can skip the Ideas table when you start with photos or AI images. Name the piece on Production if needed, and the rest of this walkthrough is the same from step 4.

      Home

      Home is the start screen. It does not run the pipeline by itself.

      • Publishing wizard — where to start, input type, counts, then a platform package.
      • Sidebar — Ideas and Production remain available as power-user paths.

      Come back here anytime to begin a new piece. The top-bar Profile selector is the city/brand for new work.

      Dashboard

      Dashboard is the queue overview. Metric cards stay on the page and filter the table under them.

      • Cards typically cover ideas waiting, production drafts, ready-for-review outputs, and publish-side states.
      • Click a card to show those records in the list below. It does not leave Dashboard.
      • Use Refresh after a promote or approve if the counts look stale.

      Open an idea or output from the filtered list, or switch to Ideas / Production / Pipeline when you need the full workspace.

      Ideas

      Ideas holds Idea Candidates before they become Content Items. Nothing here publishes.

      • Generate AI ideas — create 1–10 ideas. Studio waits until they show up in the table.
      • New idea — select an existing unpromoted candidate or enter a title/summary by hand.
      • Manage — edit copy, hold/restore, delete, or choose Add new photos / Use existing to open Production.
      • Promote to production — creates the content item from this idea. No review email is sent. Requires a summary, content type, and platforms.

      Ready to produce means the idea is in the queue. Promote it here; nothing publishes until Ready for Review → Approve publish.

      Production

      Production is where photos become a platform plan and a Content Item.

      • Start with content — title, optional description, photo cards, per-still captions, platform checks, crop pans.
      • Draft requests — unfinished production requests you can reopen.
      • Promoted content items — work that already entered render. Open Pipeline to review those outputs.
      • Advanced — exact titles, voiceover tail, extra output types. Empty EZ defaults do not overwrite saved Pipeline direction.

      Save often while uploading. Approve & Promote is the handoff into render. Music tracks shown here come from the Music Manager catalogue.

      Pipeline

      Platform Pipeline is execution plus creative review. It refreshes while the page is open.

      • Each row is one Platform Output (Reel, Story, Short, carousel, and so on).
      • Columns cover Studio state, render, review, and publish. Click a heading to sort.
      • Click a row for the creative editor: preview player, defaults, audio, ratios, slides, review notes.
      • Approve for publishing on a ready row starts live dispatch. Approve All does the same for every Ready-for-Review output after confirm.

      Publishing stays locked until that approve step. Preview-approve (when shown) records review without posting.

      Music Manager

      Music Manager is the Airtable background-music catalogue plus tracks you add as MP3 or WAV files.

      • Browse and preview tracks before or during Production.
      • Use + Add tracks or drop MP3/WAV files on this page. WAV files convert to MP3. New tracks show up in Production music pickers.
      • Delete removes the Airtable row and trashes the Drive file. Studio blocks delete if a Production Request or Content Item still selects that track.
      • It does not start a render. Production still decides Include background music Yes/No and the mix in Pipeline review.

      Asset Manager

      Asset Manager is the Drive DAM catalogue of stills and Raw Footage. Music stays on its own tab.

      • The tab opens on the 5 newest assets. Cards show an Added date when Intake_Date is known, file size when File_Size_Bytes or File_Size_MB is stored, and clips show duration (0:42 or 1:02:03) when Duration_Seconds is stored or can be measured. Use Show this many on page, then Previous and Next. Search by name or location. Opening the tab does not load every thumbnail.
      • Use + Add assets or drop files on this page. Photos go to the Drive photos folder; clips go to the video folder. Studio writes a Media Asset and does not keep a catalog copy on R2.
      • Rename updates the Airtable name and the Drive file, then re-runs classification so tags, location, and description pick up the new name.
      • Delete removes the Airtable row and trashes the Drive file when nothing still has that asset attached.
      • Show → Published files lists live Platform Outputs, not source stills or clips. Open live post confirms the public URL. Remove Drive copy trashes the rendered Drive file and keeps the Platform Output row, publish date, and post link for reporting.
      • Library intake on Operations still scans the Drive intake folder for files that did not come through this page.

      Operations

      Operations is the control room. The nav item is limited to tenant admin, publishing, and production-configure roles. Control tools sit behind the small text links at the top of the card so only one section is open at a time.

      • Autonomous Service Agent — Operations sub-page with the Word operator guide, desk mode, live stuck inventory, and Task Organizer activity log. Worker heal still runs every two minutes; the desk never auto-publishes.
      • Daily ideas — per-profile daily batch around 1:00 a.m. Chicago, or Run today now.
      • Library intake — A GitHub ticker starts A2 every 10 minutes. Process intake folder runs the same drain now. Oversized clips compress one at a time, then the next file starts immediately; A0 stays off.
      • Ready to schedule / publish — set a post time or mark a hand-posted package published.
      • Oversized library videos — compress via A1S/A1M for Drive files over 100 MB.
      • Render repair — reset stale Remotion URLs (M1) and retry failed asset selection (R2B).

      These buttons do not turn interval scanners back on. They pulse the matching on-demand scenario when work exists.
